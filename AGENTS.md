# Workspace Desktop

- `crates/workspace-core` содержит контекст Workspace, авторизацию и тесты жизненного цикла сессии.
- `crates/workspace-desktop` подключает системные адаптеры и содержит UI-компоненты Iced.
- [Архитектура](docs/plans/workspace-desktop-architecture.md) и [контракт авторизации](docs/plans/modules/auth.md) описывают границы модулей.

## Комментарии к коду

Пиши комментарии на русском простыми словами. Читатель без опыта в Rust должен понимать, зачем нужен код и что в нём происходит.

- Начинай каждый Rust-файл с короткого комментария `//!`. Объясни, зачем нужен файл, за что он отвечает и что читатель найдёт внутри. Если в файле несколько частей, перечисли их в порядке чтения.
- У каждой функции и метода добавляй короткий комментарий `///` о назначении, даже если имя говорит само за себя. Когда это помогает понять код, поясни, где или когда вызывать функцию, что она возвращает и что происходит при ошибке.
- У каждого типа и трейта объясняй, что он описывает и зачем нужен. У каждого поля структуры или варианта перечисления пиши короткий `//` справа от объявления на той же строке. Объясняй, что хранится в поле и как понимать его значение. Если важны единицы измерения или смысл `None`, укажи их там же.
- Внутри функций поясняй неочевидные решения и шаги. Обычно хватает одной-двух коротких фраз о том, зачем нужен этот шаг. Обновляй комментарии вместе с кодом.

## Работа с UI

- Для проектирования, реализации или ревью компонентов и экранов используй [Workspace Desktop UI](skills/workspace-desktop-ui/SKILL.md).
- Когда для задачи нужен актуальный макет, используй [Workspace Desktop Figma Bridge](skills/workspace-desktop-figma-bridge/SKILL.md), даже если Figma не упомянута.

## Проверки из корня workspace

```sh
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo test --workspace --no-default-features
```

[Запуск авторизации без окна](docs/plans/modules/auth.md#запуск-без-окна) описывает проверку на тестовом стенде. Галерея Iced запускается командой `cargo run -p workspace-desktop --example ui_gallery`.
