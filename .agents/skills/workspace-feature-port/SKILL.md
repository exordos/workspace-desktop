# Перенос фичи Workspace Desktop

Входные данные — функция, референс Electron и результат текущей итерации. Если в задаче есть ссылка на карточку, сначала сверь её точку продолжения с текущим состоянием репозитория.

1. Следуй [маршруту переноса](../../../docs/agents/workspace-desktop-feature-port.md). Определи ревизию референса, границы итерации и применимые проектные скиллы.
2. Обнови карточку фичи в дорожной карте. Если её ещё нет, используй [шаблон](../../../docs/plans/roadmap/ui-parity/feature-card-template.md). Для примера структуры и результатов открой [карточку папок](../../../docs/plans/roadmap/gpui-ui-parity-folders.md).
3. Доведи задачу до указанного результата итерации. Если пользователь просит план, сохрани исследование и критерии приёмки. При реализации оркестрируй независимые срезы по маршруту проекта, проверь объединённый результат и обнови точку продолжения.
