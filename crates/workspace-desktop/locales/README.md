# Переводы Workspace Desktop

При сборке Desktop `rust-i18n` читает JSON-каталоги этого дерева. Модульные файлы одного языка, например `ru.json` и `messenger/ru.json`, объединяются. Каждый ключ должен иметь только одно определение на язык. Ключи можно вкладывать в объекты или записывать через точку.

Чтобы добавить язык, создайте `<код>.json` с кодом BCP 47, например `pt-BR.json`. Укажите название языка в `locale.name` и добавьте переводы. После пересборки язык появится в списке настроек. Файлы можно разбить по модулям, сохраняя имя `<код>.json`.

Для общего текста используйте ключи и формулировки [веб-клиента](../../../../workspace_ui/packages/web/src/i18n/locales/). При переносе заменяйте маркеры `{{name}}` на `%{name}`. Для числовых форм продолжайте использовать суффиксы `_zero`, `_one`, `_two`, `_few`, `_many` и `_other` по правилам языка. Например, для русской подписи счётчика понадобятся `channel.participants_one`, `channel.participants_few` и `channel.participants_many`.

При отсутствии строки Desktop пробует общий язык региональной локали и затем русский. Для числовой подписи он заново выбирает форму в каждом из этих языков и проверяет универсальную строку `_other` перед переходом к следующему языку. Если строка пропущена во всех этих каталогах, Desktop показывает «—» и пишет ключ в диагностический журнал.
