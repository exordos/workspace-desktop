# Workspace Desktop Feature

1. **Найди сценарий.** Начни с [каталога функций](../../docs/plans/features/README.md). Если есть подходящая строка, возьми её ID, сверь основание и проверь в коде, что уже реализовано. Зафиксируй ожидаемый результат из требования задачи или согласованного сценария. Если строки нет, опирайся на задачу и уточни открытые вопросы, которые меняют результат.
2. **Определи владельцев поведения.** Открой [таблицу ответственности](../../docs/plans/workspace-desktop-architecture.md#модули-и-ответственность) и контракты затронутых модулей. Опиши, что делает `core` и какую команду, состояние или событие использует `desktop`. Правила, доступ и данные принадлежат `core`. Навигация, состояние экрана и вызовы адаптеров ОС относятся к `desktop`. Если есть фоновая работа, сверь владельца данных и обработку позднего ответа при переключении аккаунта или выходе.
3. **Реализуй и проверь один сквозной сценарий.** Для ожидаемого результата и выбора уровня проверки используй [Workspace Desktop Testing](../workspace-desktop-testing/SKILL.md). Для компонентов и экранов используй [Workspace Desktop UI](../workspace-desktop-ui/SKILL.md). Если нужен актуальный макет, подключи [Workspace Desktop Figma Bridge](../workspace-desktop-figma-bridge/SKILL.md).
