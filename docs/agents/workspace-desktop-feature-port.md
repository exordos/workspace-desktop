# Перенос фичи из Electron в Workspace Desktop

## Стартовый промпт

В чате проекта набери `$` и выбери [`workspace-feature-port`](../../.agents/skills/workspace-feature-port/SKILL.md), затем допиши функцию, референс и результат итерации.

> Перенеси **[функцию]** из Electron в Workspace Desktop. Референс — **[экран, действие или ссылка]**. В этой итерации доведи до **[результата]**.

Результат может быть планом, работающим Core или готовым сценарием в окне. Ревизию Electron можно указать в промпте. Если её нет, агент найдёт её по каталогу функций.

Для возобновления достаточно «Продолжи **[функцию]** по **[ссылке на карточку]** до **[результата]**».

## Что делает агент

1. Находит сценарий, ревизию Electron и текущий маршрут Desktop по [Workspace Desktop Feature](../../skills/workspace-desktop-feature/SKILL.md). Записывает ожидаемый результат, границы, затронутые контракты и критерии приёмки.
2. Дополняет существующий план фичи или создаёт карточку по [шаблону](../plans/roadmap/ui-parity/feature-card-template.md) в соответствующем разделе дорожной карты. Согласованный результат итерации определяет, до какого среза идти.
3. Если итерация включает реализацию, делегирует независимые срезы субагентам. Каждый получает результат, зависимости, файлы и критерии проверки. Интеграцию общих точек входа ведёт оркестратор. Для работы через очередь отдельные задачи оформляются по [формату планировщика](workspace-desktop-planner.md#формат-задачи) со ссылкой на карточку фичи.
4. Проверяет штатный сценарий после интеграции по [Workspace Desktop Testing](../../skills/workspace-desktop-testing/SKILL.md) и [Workspace Desktop Review](../../skills/workspace-desktop-review/SKILL.md). Обновляет карточку фактическими проверками, принятой ревизией или состоянием рабочего дерева и следующим шагом.
