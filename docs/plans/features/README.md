[Пользовательские сценарии и тест-кейсы](../testing/README.md) дополняют каталог проверками поведения и связей между функциями.

## Дерево модулей

- [Мессенджер](messenger/index.md) — разговоры, навигация, история и действия, редактор, черновики, файлы, непрочитанное, активность, E2EE, опросы и интеграции.
- [Другие разделы Workspace](sections/index.md) — звонки, почта, календарь, сервисы и лицензии.
- [Общие модули](foundation/index.md) — авторизация, каталог пользователей, оболочка, настройки, синхронизация, уведомления и интеграция с ОС.

Иерархия показывает, где искать функцию. Ссылки между строками показывают, какие модули участвуют в одном сценарии. Например, выбор разговора начинается в [навигации](messenger/navigation.md), поведение при отключении звука принадлежит [правилам непрочитанного и уведомлений](messenger/unread.md), а показ баннера — [десктопной доставке уведомлений](foundation/notifications.md).

## Как читать таблицы

| Поле | Значение |
| --- | --- |
| ID | Постоянный идентификатор со ссылкой на строку. Например, [`AUTH-001`](foundation/accounts.md#auth-001). |
| Функция и сценарий | Что должен уметь клиент и при каких условиях. |
| Основание | **Референс** — поведение React/Electron. **План** — требование из плана Workspace Desktop. **Ветка** — возможность из отдельной ветки. **Уточнить** — кандидат, ограничение референса или открытый вопрос. |
| Арх. | Сценарий явно учтён в архитектуре Workspace Desktop. |
| Проект | Для сценария описаны контракт, поведение и важные случаи сбоя. |
| Код | Сценарий реализован в Desktop. Готовность UI на GPUI проверяй отдельно по [плану перехода](../workspace-desktop-roadmap.md#предлагаемый-переход-на-gpui). |

`□` — подтверждение отсутствует. `✓` — есть основание для отметки. Для `✓` указываем ссылку на решение, проектирование или код. Три отметки независимы. При необходимости к строке можно добавить ссылку на отдельное описание сценария, задачу или проверку. При переносе строки между файлами обновляем входящие ссылки и сохраняем ID.

## Источники

Основной референс — локальный `workspace_ui`, ветка `fix/chats`, коммит `af099988`. Для серверных контрактов использован локальный `workspace_backend` (`bc986e0`). Относительные ссылки на источники рассчитаны на соседние каталоги репозиториев. Возможности из других ревизий помечены в соответствующих строках. [Маршруты React](../../../../workspace_ui/packages/web/src/app/app-route-definitions.tsx) · [Код Electron](../../../../workspace_ui/packages/electron/src/main.ts) · [План Workspace Desktop](../workspace-desktop.md)

Доступность функций, зависящих от сервера, прав, сборки или платформы, указана по исходникам. Развёрнутые стенды и установленные сборки требуют отдельной проверки. Предложения со статусом «Уточнить» требуют решения о включении в объём работ.
