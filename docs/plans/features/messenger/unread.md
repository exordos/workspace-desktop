# Непрочитанное и уведомления мессенджера

[Мессенджер](index.md)

Мессенджер ведёт статусы чтения, счётчики и правила показа уведомлений. Системная доставка получает контекст и цель перехода из мессенджера. [Путь события](../../workspace-desktop-architecture.md#путь-события)
