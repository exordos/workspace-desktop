# Навигация, список чатов и папки

[Мессенджер](index.md)

Сайдбар показывает разговоры и вызывает операции их владельцев. Жизненный цикл канала описан в [разговорах](conversations.md), прокрутка и поиск по содержимому — в [истории](history.md).
