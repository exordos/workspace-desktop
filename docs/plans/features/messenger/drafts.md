# Черновики

[Мессенджер](index.md)

[Проектирование черновиков](../../modules/messenger-drafts.md)

Черновик принадлежит аккаунту и разговору. [Редактор](composer.md) его меняет, раздел активности даёт найти и открыть сохранённый черновик.
