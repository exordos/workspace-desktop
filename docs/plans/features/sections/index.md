# Разделы Workspace

[Карта функций](../README.md)

| Модуль | Что входит |
| --- | --- |
| [Звонки](calls.md) | Jitsi в чатах, входящие, окно конференции, недавние звонки. |
| [Почта](mail.md) | Встроенный экран в референсе, сценарии и контракты для нативного раздела. |
| [Календарь](calendar.md) | Встроенный экран в референсе, расписание, приглашения и напоминания для уточнения. |
| [Сервисы и лицензии](services.md) | Каталог сервисов, лицензии зависимостей приложения. |

Звонки получают приглашения из [мессенджера](../messenger/index.md). Для почты и календаря общие границы авторизации, фоновой работы и уведомлений описаны в [архитектуре](../../workspace-desktop-architecture.md#модули-и-ответственность).
