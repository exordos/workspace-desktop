# Копирование из сообщения

[Дерево проверок](README.md) · [MSG-HIST-021](../features/messenger/history.md#msg-hist-021) · [Контракт меню](../roadmap/ui-parity/ui-14-bubble-menu.md)

Это начальные кейсы по контракту меню. Подтверждения существующими тестами и нативным прогоном ещё не сверены.

### COPY-01. Текст и выделенный фрагмент

- **Функции:** [MSG-HIST-021](../features/messenger/history.md#msg-hist-021).
- **Дано:** открыто подтверждённое сообщение с текстом.
- **Действие:** вызвать «Копировать» из его контекстного меню; повторить с выделенным фрагментом этой строки.
- **Ожидаем:** в буфере оказывается текст сообщения или выделенный фрагмент соответственно. Содержимое и состояние сообщения не меняются.
- **Проверка:** GPUI с управляемым буфером и нативное окно с системным буфером. Подтверждения ещё не сверены.

### COPY-02. Ссылка внутри сообщения и ссылка на сообщение

- **Функции:** [MSG-HIST-021](../features/messenger/history.md#msg-hist-021), [MSG-NAV-015](../features/messenger/navigation.md#msg-nav-015).
- **Дано:** сообщение содержит HTTP(S)-ссылку и имеет публичный UUID.
- **Действие:** скопировать ссылку из текста, затем отдельно скопировать постоянную ссылку на сообщение и открыть её.
- **Ожидаем:** в первом случае буфер содержит только URL из текста. Во втором — ссылку текущей организации и проекта на сообщение; открытие ведёт к нужному контексту и строке при доступе к ним.
- **Проверка:** GPUI и проверка перехода через рабочий клиент; системный буфер — в нативном окне. Подтверждения ещё не сверены.

### COPY-03. Защищённое содержимое и отзыв доступа

- **Функции:** [MSG-HIST-021](../features/messenger/history.md#msg-hist-021), [шифрование](../features/messenger/encryption.md).
- **Дано:** открыто доступное расшифрованное сообщение; в другом прогоне доступ отзывается после открытия меню.
- **Действие:** скопировать доступный текст; повторить действие после отзыва доступа.
- **Ожидаем:** доступное поддерживаемое тело копируется. При отзыве допуск проверяется повторно до записи в буфер, недоступное содержимое не записывается.
- **Проверка:** GPUI с управляемым отзывом и буфером; нативный системный буфер — отдельно. Подтверждения ещё не сверены.

## Следующие ветки

Отдельно расписать копирование изображений, HEIC, смешанного защищённого Markdown и семантического времени с учётом ограничений [контракта меню](../roadmap/ui-parity/ui-14-bubble-menu.md). Уточнить пользовательский результат ошибки записи в системный буфер: найденный контракт его не определяет.
