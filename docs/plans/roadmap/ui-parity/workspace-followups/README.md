# Доработки Workspace для переноса в Desktop

Здесь фиксируются доработки Workspace, поведение которых нужно сразу учесть при реализации соответствующего сценария в Workspace Desktop.

Перед переносом сверяй заметку с актуальным Workspace и Electron-референсом, затем добавляй сценарий и критерии приёмки в план конкретной функции.

## Заметки
