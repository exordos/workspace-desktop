# Горячие клавиши Workspace

## Поиск и переход в канал

Зафиксировано по описанию пользователя; актуальное поведение Workspace нужно сверить перед переносом.

- `Cmd+K` на macOS и `Ctrl+K` на остальных платформах сразу открывает поиск и ставит фокус в строку поиска. Первое действие — поиск каналов, а не список недавних чатов.
- Стрелки `↑` и `↓` перемещают выделение по найденным результатам. `Enter` открывает выделенный канал.
- После перехода в канал клавиатурный фокус автоматически перемещается в поле ввода сообщения. Каретка готова к набору; существующий черновик сохраняется, если он есть.

### Критерии приёмки для Desktop

1. Нажатие `Cmd+K` или `Ctrl+K` открывает поиск с активной строкой поиска.
2. Запрос фильтрует список каналов; стрелки меняют выделенный результат, а `Enter` открывает выбранный канал.
3. После открытия канала фокус находится в поле ввода сообщения, и следующий набранный текст попадает туда без дополнительного нажатия мышью или `Tab`.
4. Если в канале есть черновик, он остаётся на месте, а каретка стоит в конце текста.
