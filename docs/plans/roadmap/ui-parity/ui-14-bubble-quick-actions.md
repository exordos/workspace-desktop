## Результат итерации

При наведении на читаемое сообщение видны быстрый ответ и реакция. Первая реакция переключается кликом. Наведение на неё раскрывает набор. Закрытое зашифрованное сообщение с недостающим ключом показывает запрос для этой строки. Одно место над пузырём принимает подходящее действие.

## Референс и решения

Референс Electron — `workspace_ui@af0999886daaffefc2a7be33f8dcf3f484a0e9c1`. Кнопка ответа появляется при наведении или фокусе и передаёт выделенный в этом сообщении текст в композер. Входящий и исходящий пузырь размещают кнопки с внутренней стороны. Значок реакции переключает первый эмодзи списка, удержание указателя раскрывает прокручиваемую полосу. Для закрытого сообщения виден запрос точного ключа, во время операции он недоступен. Порядок по умолчанию — ❤️ 👍 😂 😮 😢 👏. К ним добавляются до пяти других эмодзи по числу подтверждённых добавлений. Частота сортирует весь набор. При равной частоте базовые реакции держат исходный порядок. Для остальных известных эмодзи Desktop использует порядок Unicode-коллации Electron, зафиксированный в каталоге. В окно входят текущий и шесть предыдущих дней по UTC. Счётчик растёт только после успешного локального добавления. ## Границы и контракты

- База Desktop — рабочее дерево `main@88bba07`. Переиспользуем проверку источника цитаты, добавление ответа в композер и запрос существующего или исторического ключа.
- Core связывает подтверждённую реакцию с сообщением и владельцем. Дневные счётчики принадлежат локальному профилю и контексту аккаунта и проекта. Desktop берёт ранжированный список из `QuickReactionUsage`. Та же модель и команда переключения доступны для будущей полосы в меню.
- Блок быстрых действий относится к штатным строкам истории. Служебные строки, превью и строки локальной очереди используют свои действия. Пока недоступно расшифрованное тело, виден только применимый запрос ключа.
- Меню, поиск эмодзи и его клавиатурный маршрут ведутся в [M6 контекстного меню](ui-14-bubble-menu.md#карточки-реализации).

## Карточки реализации

| Срез | Владелец | Готово, когда |
| --- | --- | --- |
| Команда реакции | `workspace-core::messenger`, история и Sync | Один клик добавляет или снимает собственную реакцию. Подтверждённый счётчик приходит в открытое окно, в том числе через realtime. |
| История популярности | `workspace-core::messenger::quick_reactions`, SQLite | В пустом профиле видны шесть базовых. Частый эмодзи поднимается, дни старше окна исчезают, входы не смешиваются. |
| Аксессуары пузыря | `Conversation`, `Viewport`, общий пузырь GPUI | Ответ открывает композер, запрос использует точный ключ, из угла можно выбрать реакцию без сдвига строки при наведении. |

## План проверки

| Уровень | Действие | Ожидаемый результат |
| --- | --- | --- |
| Core | Записать счётчики в крайние дни, сменить день и профиль, повторно открыть SQLite | Истекающие дни уходят из рейтинга, псевдонимы объединяются, данные другого владельца не появляются. |
| Core и GPUI | Добавить и снять реакцию, получить событие или отказ | Видны итоговый счётчик и собственная реакция. Только подтверждённое добавление меняет популярность. |
| GPUI | Навести на читаемый пузырь или реакцию, выбрать ответ или эмодзи, открыть сообщение без ключа | Кнопки остаются доступны на пути указателя. Ответ и запрос адресуют исходную строку. У закрытого сообщения реакции скрыты. |

## Точка продолжения

- В рабочем дереве подключены панель пузыря, существующие команды ответа и запроса ключа, реакции через REST и журнал и общий рейтинг.
- Прошли проверки архитектуры, семидневного рейтинга, сохранения и изоляции в SQLite, добавления и снятия через локальный HTTPS в Core и защиты цитат и правки от обновления реакций.
- В GPUI подтверждены раскрытие без сдвига пузыря, выбор мышью и клавиатурой, постоянная видимость запроса ключа и три сценария сохранения черновика после быстрого ответа.
- Сквозной тест GPUI проверил добавление эмодзи из пузыря через HTTPS, появление счётчика, снятие по клику на счётчик и восстановление высоты строки.
- Тесты библиотек и интеграций прошли без GPUI. В расширенном прогоне GPUI упали проверки превью каталога, перехода к теме в сценарии пересылки и селектора заголовка канала. Проверка защищённого звонка прошла при отдельном запуске. Сборку всех целей останавливает пример macOS с устаревшим вызовом `Tray::install`.
- После проверок панель прижата к границе истории в узком окне. Повторный запуск GPUI-тестов блокируют ошибки компиляции в параллельных изменениях сайдбара, в том числе отсутствующий модуль `catalog_actions/contact.rs`.
- Контекстное меню подключает существующий источник при выполнении M6.
