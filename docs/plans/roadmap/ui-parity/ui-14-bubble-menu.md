## Результат итерации

В штатной истории GPUI правый клик строит пункты по фактической строке, попаданию в содержимое и состоянию разговора. Действия с готовыми операциями подключаются к своим владельцам. Если действие по правилам Electron должно появиться, но операция ещё ждёт реализации, пункт виден и отключён. Стрелки его пропускают, Enter и клик не выполняют команду. Порядок и подписи остаются стабильными при включении операции.

Правка, копирование и пересылка открываются из контекстного меню. Переход к оригиналу пересылки открывается по её заголовку.

## Границы и контракты

- Desktop `main@88bba07` с локальными изменениями. В истории уже есть меню ответа на обычный Markdown, выделение, режимы ответа и правки в Composer, защищённый буфер обмена, запрос ключа, редактирование фрагментов, диалог пересылки защищённого снимка и просмотр вложений. Core уже проверяет авторство и адрес удаления, получает квитанцию мутации и получает изменения истории через штатную синхронизацию.
- `Conversation` связывает действие с адресом разговора и публичным UUID. История получает попадание и выделение из раскладки строки. `workspace-core::messenger` проверяет видимость, права, шифрование, версии, операции и очередь. Открытое меню, подтверждение и поздние результаты привязаны к поколению входа и ревизии маршрута. Тело закрытого сообщения не переносится в открытое меню или журнал.
- Переиспользуем `ui::popup` для поверхности, размещения, обхода клавиатурой и закрытия, `Button` и `Icon` для строк, `RightPanel` для размещения диалога, `Composer` для цитат и правки, текущие карточки для файлов. Специфичные части истории — описание команды, группы пунктов, полоса реакций и подтверждение удаления. Общий UI принимает подписи, состояние и событие выбора.
- Сохраняем язык аккаунта через `rust-i18n`. Проверяем доступность повторно при выборе команды. При смене аккаунта, ревизии разговора, удалении строки или отзыве доступа локальная поверхность закрывается. При отзывном содержимом повторная проверка действует и перед записью в буфер.

## Точка продолжения

- В рабочем дереве подключены основной сценарий M1 и части M2–M4 и M6. Меню открывается по попаданию в бабл, ссылку или карточку изображения. Подключены текст, URL, постоянная ссылка, PNG/JPEG/WebP, оригинал HEIC, запрос ключа, готовые операции ответа и правки, одиночная пересылка, подтверждение удаления и быстрые реакции. Удаление после подтверждения API сходится через журнал и штатное обновление окна.
- Пересылка использует общий хост модального окна и отдельную проекцию целей. Для обычного источника можно выбрать существующую личку или явную открытую тему, а также «Избранное», когда чат с собой есть в каталоге. У источников с защищёнными фрагментами сохранён старый маршрут с каноническим снимком. Постоянная ссылка использует HTTPS-хост аккаунта. Поддержка развёртывания с отдельным веб-хостом требует адреса в настройках или данных сессии.
- Видны отключённые «Выбрать», «+» у реакций, «Копировать изображение» для HEIC и операции, для которых в конкретном разговоре ещё нет подходящего владельца. Отдельно нужны модель опроса, поиск в каталоге пользователей с созданием цели, групповые операции, обработка ссылок внутри расшифрованного текста под отзывным допуском и форматирование меток времени при копировании. HEIC сейчас распознаётся по расширению имени.
- Прошли два теста Core на permalink, обычная пересылка выделения и защищённая пересылка через локальный HTTPS, а также `cargo check-architecture` и `git diff --check`. Прошли 12 GPUI-тестов меню и цитирования, включая правый клик на конкретной ссылке, обход отключённых действий, открытие клавиатурой, отзыв устаревшей цели и быстрый ответ. Отдельно прошли допуск удаления и проекция целей пересылки. Сквозной тест защищённой пересылки дошёл до подтверждения сервера и проверки снимка, затем остановился на открытии темы назначения из каталога.
- Для отметки полного паритета нужны оставшиеся части M1–M6 и сравнение двух нативных окон. Пока размеры и цветовые состояния сверены по исходникам Electron и кадру Figma.
