# UI-02. Фиксированные сцены для сверки

[Матрица UI-01](../gpui-ui-parity-baseline.md) описывает границы сценариев. В [scenes.json](scenes.json) лежат общие данные для Electron и будущих полнооконных сцен GPUI. В наборе два вымышленных профиля без аватаров, нешифрованная личка и канал с двумя темами. Одна тема содержит сообщения, другая используется для загрузки, ошибки и пустой истории. Для статусов отправки исходное сообщение одно и то же. Даты, порядок, авторы и содержимое фиксированы.

## Запуск оригинала

Нужен macOS, Node.js 22+ и репозиторий `workspace_ui`, в котором доступен `af0999886daaffefc2a7be33f8dcf3f484a0e9c1`. Выполни из корня Workspace Desktop. Оба пути в `/private/tmp` должны быть свободны. Порт `43170` должен быть свободен.

```sh
git -C /Users/adam/t-tech/workspace_ui worktree add --detach \
  /private/tmp/workspace-ui-parity-original af0999886daaffefc2a7be33f8dcf3f484a0e9c1
(cd /private/tmp/workspace-ui-parity-original && env SKIP_SIMPLE_GIT_HOOKS=1 npm ci --no-audit --no-fund)
docs/plans/roadmap/gpui-ui-parity-fixtures/capture-electron.sh \
  /private/tmp/workspace-ui-parity-original /private/tmp/workspace-ui-parity-electron
```

Сценарий проверяет чистоту и SHA worktree. Он собирает renderer по lockfile, поднимает локальный Vite preview, подключает исходные Electron `main` и `preload` и переиспользует REST-моки оригинала. Обёртка задаёт адрес локального сервера и временный профиль, отключает автообновление и отдельное окно DevTools и разрешает выставить размер области содержимого независимо от размеров дисплея. При первом открытии сценарий закрывает плашку уведомлений кнопкой «Не сейчас». Она сохраняет исходные preload, sandbox, маршруты чатов и элементы окна. Синтетические сессии заполняются через `localStorage`. Сеть сценария ограничена loopback и моками, Chromium использует тестовую связку ключей. Нужные для запуска пакеты npm и Electron публикуются отдельно от данных приложения.

В одном экземпляре `BrowserWindow` сценарий переводит приложение в каждое состояние, ждёт наблюдаемого результата с тайм-аутом 15 секунд на проверку и сохраняет пару `ID.png` и `ID.json`. Статус выхода ненулевой, если хотя бы один кадр не снят. Перечень сцен в порядке прогона есть в `scenes.json`.

## Условия и кадры

Все 11 сцен сняты через `BrowserWindow.capturePage()` в Electron 42.11.0 на macOS 27.0.1. Журнал миграции указывает каталог PNG и JSON. Для переключения аккаунта, контекстных меню, поиска и раскрытой правой панели остаются эталоны из [матрицы UI-01](../gpui-ui-parity-baseline.md). Эти действия за пределами набора UI-02.

- Сравнивай области содержимого 1440 × 900 и 700 × 600 логических px при масштабе 100%, DPR 1. `capturePage()` снимает содержимое нативного `BrowserWindow`. Координаты системных кнопок и границы области сохраняются в JSON. Для вида системной рамки нужна отдельная проверка macOS.
- Используй русский интерфейс, Blue Mist в обоих режимах, время `2026-07-16T12:30:00.000Z` и `Europe/Moscow`, системный шрифт macOS из стека `system-ui`. Используй одну версию ОС при повторных замерах. На macOS 27.0.1 окно штатно ограничивается доступной высотой экрана. Обёртка разрешает выставить 900 px, когда рабочая область дисплея ниже.
- Правая панель закрыта, каталог и шапка готовы. Перед кадром сценарий ждёт шрифты, останавливает анимации и переходы, скрывает каретку и ждёт два кадра браузера. У индикатора загрузки фиксируется первый кадр. Для GPUI используй те же сценарий, данные, размер и тему, затем сравнивай область содержимого. Разрешённый порог отличий определят повторные прогоны UI-03.
