# UI-10. Клавиатурная навигация и доступность

Основание — [PREF-006](../features/foundation/preferences.md#pref-006) и Workspace Electron `af099988`. В оригинале `top-bar.ui.tsx` и `layout-main-workspace.ui.tsx` объявляют именованные области DOM, а `packages/electron/src/main.ts` добавляет команды масштаба содержимого `zoomIn`, `zoomOut` и `resetZoom` в меню окна.

## Маршрут с клавиатуры

1. `Tab` проходит доступные быстрые кнопки аккаунтов и кнопку «Выбрать аккаунт». `Enter` открывает меню. Стрелки меняют выбранную строку, `Enter` выбирает аккаунт, `Escape` закрывает меню. В обоих случаях фокус возвращается кнопке.
2. После кнопки выбора аккаунта `Tab` переводит фокус в поиск. Введите часть имени лички, нажмите `↓` и `Enter`. Фокус остаётся у выбранной строки, следующий `Tab` переводит его в историю. При наличии дополнительных действий догрузки они входят в обход перед историей.
3. В истории `↑` и `↓` прокручивают строки, `Page Up` и `Page Down` прокручивают страницу. `Home` переходит к началу загруженного фрагмента. При повторном движении за загруженный край запрашивается следующая порция, если для неё есть маркер. `End` возвращает к последним сообщениям. В пустой истории фокус стоит у подписи «Сообщений пока нет».
4. Следующий `Tab` у хвоста переходит в редактор лички. `Shift+Enter` добавляет строку, `Enter` отправляет готовый черновик. Обратный обход `Shift+Tab` возвращает фокус в историю и строку каталога. Доступные дополнительные действия разговора входят в обычный обход.

## Видимое состояние

У кнопок, строк каталога, полей и истории есть контрастная рамка фокуса. Для Blue Mist в автоматическом тесте проверены контраст рамки не ниже 3:1 и контраст времени сообщений, подписи выбранной строки, пояснения ошибки и чисел в счётчиках не ниже 4,5:1 в обеих темах. Доставка различается значками и, для незавершённых и неудачных операций, текстом. Например, неопределённый результат отмечен фразой «Исход неизвестен. Ищем сообщение».

У быстрых кнопок есть подсказки с именами аккаунтов. Остальные пиктограммы действий подписаны подсказками «Выбрать аккаунт», «Очистить поиск» и «Отправить (Enter)». Значок «Чаты» показывает текущий раздел.

## Ограничения доступности

GPUI 0.2.2 рисует содержимое в собственном AppKit-представлении и не предоставляет API для регистрации его элементов в дереве AX. Подсказки видны в окне. VoiceOver через них не получает имена кнопок, текста поля и истории. Проверка AppKit-дерева одного синтетического окна проводится при приёмке и сохраняется в журнале. Системные элементы рамки окна относятся к AppKit.

Команды масштаба содержимого Electron пока отсутствуют в GPUI-клиенте. Размеры ролей текста в `ui/theme.rs`, поля поиска и редактора закреплены в логических пикселях. Изменение масштаба дисплея macOS влияет на плотность вывода. Смена размеров окна изменяет переносы и видимую область, размер текста приложения остаётся прежним.

## Проверки

```sh
cargo test --locked -p workspace-desktop --features gpui-test --lib catalog_click_and_submission_reach_https_queue
cargo test --locked -p workspace-desktop --features gpui-test --lib history_keys_scroll_and_load_older_page
cargo test --locked -p workspace-desktop --features gpui-test --lib status_text_and_focus_keep_contrast_in_both_themes
```

Первый тест проходит клавишами от шапки через поиск и список в историю и редактор, затем обратно. Отправка проходит через локальный HTTPS и очередь SQLite. Второй проверяет прокрутку и догрузку на истории из 600 сообщений. Остальные проверки редактора покрывают IME, вставку и сохранение черновика.
