# UI-04. Тема и примитивы

Основа сравнения — `workspace_ui@af0999886daaffefc2a7be33f8dcf3f484a0e9c1` и [кадры из UI-02](gpui-ui-parity-fixtures/README.md). Для сравнения размеров берём логические пиксели. Electron снят с DPR 1, GPUI на Retina — с DPR 2. Цвета в таблице заданы в sRGB. Скриншоты сверяем с учётом профиля, сглаживания и масштаба.

В Figma Bridge сверены `Exordos Core (Copy)`, палитра `Palette new` (`11699:34650`), тёмный Blue Mist (`11699:34711`), светлый Blue Mist (`11698:33817`), набор мессенджера (`1477:5484`) и готовая личка (`2473:7898`). Фрейм лички показывает другой тёмный вариант с фоном `#1b1b1d`, поэтому цвета Blue Mist берём из выделенной палитры и оригинала. В типографической секции (`40:27051`, слой `36:17926`) образец Helvetica Neue 13/18. В готовой строке Electron используются роли 14/20 и 12 px и системный шрифт. Для GPUI сохраняем системный шрифт macOS и соответствующие роли 14/20 и 12/18.

GPUI сохраняет контрастный цвет текста бейджа. Он даёт 5,55:1 и 5,61:1 на синем фоне светлого и тёмного режима. Белый текст Electron в тех же парах даёт 3,15:1 и 3,17:1. Для приглушённого бейджа GPUI даёт 7,34:1 и 5,09:1. Контрольный тест проверяет порог 4,5:1 для четырёх пар. Основной текст выбранной строки даёт 12,33:1 и 9,35:1. У подписи выбранной строки текущие пары дают 3,66:1 и 4,01:1. Проверка контраста распространяется на бейджи. Фокус кнопки и строки пока рисуется нативной контрастной границей 1 px. Положение лупы и компоновка метаданных остаются задачей UI-06, а размеры редактора и его кнопок — UI-08.

## Сравнить изменение

```sh
cargo run --locked -p workspace-desktop --example ui_scene -- \
  chat-row light 700x600 /private/tmp/workspace-ui-04-light --verify
cargo run --locked -p workspace-desktop --example ui_scene -- \
  chat-row dark 700x600 /private/tmp/workspace-ui-04-dark --verify
cargo run --locked -p workspace-desktop --example ui_gallery
cargo test --locked -p workspace-desktop --all-targets --features gpui-test
```

С исходными кадрами UI-03 сопоставляем одну область строки при том же размере и масштабе. Фон аватара меняется от мягкого акцента к фону окна, а круг получает обводку. Счётчик увеличивается с 16 до 20 логических px. Высота строки остаётся 60 px в GPUI. Повтор `ui_scene --verify` проверяет, что на одинаковых параметрах кадры совпадают, а контрольный сдвиг виден в diff. Полное сравнение экрана остаётся в следующих карточках паритета.
