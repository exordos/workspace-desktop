# UI-08. Редактор и отправка

Редактор разговора хранит текст, выделение, композицию IME и версию черновика. Доступность отправки для лички подтверждает рабочий поток. Экран передаёт снимок текста и адрес очереди, а успешная запись очищает только отправленную версию. Ошибка записи оставляет текст. Статус доставки после записи показывает история. [Контракт отправки](../modules/messenger-send.md).

## Проверка

```sh
cargo test --locked -p workspace-desktop --features gpui-test --lib gpui_client::conversation::send_tests
```

Тесты через рабочее представление разговора сверяют размеры и перенос при ширине разговора 650 и 340 px, верхнюю опору при чтении истории и нижний отступ последнего сообщения у хвоста. Проверены вставка с CRLF, 50 строк с ограничением высоты, отказ при 40 001 кодовой точке, сохранение текста при ошибке, повтор, поздний ответ и IME через интерфейс ввода AppKit.

Для общего прогона прикладного окна macOS на синтетике открой личку, сфокусируй пустое поле, введи одну строку и добавь вторую через Shift+Enter. Вставь несколько абзацев и сузь то же окно с 1440 до 700 px. Проверь, что редактор остаётся над нижним краем, фокус и текст сохраняются, а история удерживает читаемую строку или последний элемент у хвоста. Подтверди Enter. Если в тестовом источнике задан сбой записи, проверь пояснение и повтор с прежним текстом. Для нативной IME используй настроенный системный источник ввода, подтверди композицию и нажми Enter ещё раз для отправки.
