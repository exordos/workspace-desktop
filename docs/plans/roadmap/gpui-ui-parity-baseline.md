# UI-01. Матрица отличий и эталоны Workspace

Оригинал для всех строк — macOS Electron с React из `workspace_ui@af0999886daaffefc2a7be33f8dcf3f484a0e9c1`. Штатный GPUI — `workspace-desktop@70fd3c02061583b6bd8698a5a51732d1f0713ae6` (карточки GPUI-01…21). На этих ревизиях сверены указанные исходники и макеты. Маршруты и сценарии привязаны к [каталогу функций](../features/README.md#источники).

На этапе UI-01 проверены имена, ID и наличие экспорта Figma. Исходники и Storybook дополняют [фиксированные сцены UI-02](gpui-ui-parity-fixtures/README.md). Статус кадров отдельных состояний и ограничения нативной рамки записаны рядом с командой запуска UI-02.

## Условия сравнения

- В обоих клиентах использовать синтетический нешифрованный личный чат и канал с двумя темами. Для проверки достаточно коротких и длинных названий, пустой истории, загрузки с ошибкой, серии входящих и исходящих сообщений, непрочитанного счётчика и двух аккаунтов. Закреплённый набор данных относится к UI-02.
- Основной размер для первого сравнения — область содержимого 1440 × 900 логических px, масштаб 100%, DPR 1 для захвата, русский интерфейс, фиксированные время и часовой пояс. Узкое окно начать со штатного минимума Electron 700 × 600, записать его измеренную область содержимого и выставить такую же в GPUI. У Electron на macOS `titleBarStyle: "hiddenInset"`; положение системных кнопок записать отдельно. Макеты Figma 1920 × 1080 служат для чтения композиции, их размеры не переносятся в окно напрямую.
- Сначала сравнить Blue Mist в светлом режиме, затем ту же палитру в тёмном. В оригинале настройки позволяют выбирать палитру и режим отдельно; палитра по умолчанию в реестре — Blue Cold. В GPUI Blue Mist выбирает светлые или тёмные цвета по системному виду окна. Для повторов записать шрифт и дождаться готовности каталога и истории перед захватом.
- Корень путей React в матрице — `packages/web/src/`. Общий маршрут личного чата — `/org/:orgId/project/:projectId/stream/:streamUuid`, темы — тот же маршрут с `/topic/:topicUuid`; оба ведут в `pages/chat/chat-page.ui.tsx` через `app/app-route-definitions.tsx`. В таблице режимы «сверить» и «перенести» относятся к будущим карточкам.

## Как воспроизвести источники

- Figma Bridge, документ `Exordos Core (Copy)`, страница `design макеты (desktop)` `151:2290`, секция `Messenger` `2473:13434`. Экспортируй указанный frame по ID. Варианты лички и темы — 1920 × 1080 по границам слоёв, правая панель у обеих 315 px по слою. Это размеры макета. Нативные размеры и поведение берём из воспроизводимого запуска оригинала.
- Storybook из checkout на указанном коммите Workspace UI: `npm run --workspace=web build-storybook -- --output-dir /tmp/workspace-ui-01-storybook`. Открой `iframe.html?id=widgets-messagecomposer-encryptedspoiler--multiline&viewMode=story` через локальный сервер. Для режима и языка задай `globals=palette:blue-mist;mode:dark;locale:ru` или соответствующий светлый режим. Для панелей и истории есть отдельные истории, они не заменяют целый разговор.
- GPUI-примеры на текущем коммите описывает [план прототипа](gpui-probe.md). В журнале миграции лежат синтетические кадры `07/chat.png` с прототипом `a31eb16c83c1eb8b51212b4ac802bcdc42925f37` и `18/native/gallery-final.png` с обоими режимами Blue Mist `78eefd92bb286b1032405da45f6ac3dd5a5c6e8e`. Прогон GPUI-21 подтверждает поведение штатного пакета на `70fd3c0`; старые кадры подтверждают прототип и галерею на их собственных ревизиях.
