# UI-12. Базовый сценарий мессенджера

Исходный Electron — `workspace_ui@af0999886daaffefc2a7be33f8dcf3f484a0e9c1`. Состояния и данные берутся из [сцен UI-02](gpui-ui-parity-fixtures/README.md). Для внешнего вида сравниваются готовая личка и открытая тема в светлой Blue Mist при 1440 и 700 логических px. Отдельные сцены покрывают загрузку, пустую историю, ошибку и тёмную тему. Для широкого нативного окна AppKit ограничивает высоту дисплеем. Геометрический тест использует 1440 × 900 и 700 × 600.

## Проверка сценария

| Путь | Доказательство |
| --- | --- |
| Личка в широком и узком окне | `catalog_click_and_submission_reach_https_queue` выбирает чат клавиатурой, читает историю, переносит черновик между размерами, повторяет отправку мышью после локального отказа. В очереди пусто после подтверждённого POST. |
| Тема в широком и узком окне | `explicit_topic_accepts_mouse_and_keyboard_in_each_account` открывает канал и тему мышью в B при 1440 × 900. При 700 × 600 возвращается к A клавиатурой и открывает тему через поиск. В обоих входах видна исходная строка, каждому действию отвечает собственное сообщение в SQLite, а сервер получает ровно один POST на действие. Явная тема отличается от темы канала по умолчанию. |
| Отказ записи и защищённые маршруты | `explicit_topic_is_rechecked_before_queue_and_before_post` закрывает тему после открытия редактора, проверяет пояснение и пустую очередь. Для ранее сохранённых целей повторный preflight останавливает закрытую тему, зашифрованный канал, тему чужого стрима и ответ без `is_done` до POST. |
| Клавиатура и нагрузка | [UI-10](gpui-ui-parity-accessibility.md) проверяет фокус и возврат окна. [UI-11](gpui-ui-parity-stability.md) проверяет опору, хвост, ввод и повторяемость замеров. |

Нативный сценарий использует один синтетический Client, через кнопки и клавиши открывает маршруты, показывает историю и ввод в редакторах и подтверждает, что локальное действие приняло текст. Его источник истории и запись очереди синтетические. Доставку, адрес и сохранение подтверждает отдельный прогон рабочего runtime на локальном HTTPS/WSS.

## Отличия, влияющие на работу

| Сценарий из [матрицы](gpui-ui-parity-baseline.md) | Различие и влияние |
| --- | --- |
| Выбор аккаунта, оболочка | AppKit показывает системный заголовок отдельно. Слева зарезервировано место папок, без их действий. Ширина каталога зависит от окна, отдельного перетаскиваемого разделителя нет. Верхняя панель показывает раздел чатов и доступные операции выбора аккаунта. Папки, профиль, добавление и выход из организации из меню не входят в этот путь. [UI-05](gpui-ui-parity-shell.md) |
| Список и поиск | GPUI получает каталог по имени, Electron сортирует по активности. Аватары, присутствие, превью, время и построчные счётчики в нативных кадрах добавлены фиксированными данными. Рабочий список получает сводку аккаунта и не проецирует эти поля на строки. Поиск по именам и заголовкам тем работает, поиск по адресу почты и имени входа требует каталога пользователей. Загрузка обозначена текстом. [UI-06](gpui-ui-parity-sidebar.md) |
| Шапка, история, статусы | У темы видны её название и канал. В шапке нет числа участников и статуса присутствия. История показывает текст с переносами и состояния доставки, без полной разметки исходника. Дата и время в GPUI выводятся по данным сообщения, тогда как Electron использует местное форматирование и относительные даты. На узком окне это заметно рядом с длинным заголовком и пузырями. [UI-07](gpui-ui-parity-history.md) |
| Редактор и отправка | В GPUI доступны обычный текст и выбор явной открытой темы. Поле растёт по переносам. E2EE, вложения, голос, визуальная разметка и панель быстрых действий требуют отдельных сценариев. Изменение доступа перед записью оставляет текст в поле. Экран показывает результат доставки из очереди. [UI-08](gpui-ui-parity-composer.md) |
| Контекстные меню и сведения | Меню каталога возвращает фокус и содержит действия навигации. Папки, отметки прочтения, команды над сообщением и правая панель сведений относятся к UI-13, UI-14 и UI-16. [UI-09](gpui-ui-parity-menus.md) |
| Тема оформления, масштаб, доступность | GPUI переключает Blue Mist по оформлению macOS. Выбор палитры относится к настройкам. Привычный масштаб содержимого Electron отсутствует. AX-дерево содержит системные элементы окна, основные контролы недоступны VoiceOver. Настраиваемые сочетания относятся к [PREF-005](../features/foundation/preferences.md#pref-005). [UI-10](gpui-ui-parity-accessibility.md) |

## Воспроизведение

```sh
cargo test --locked -p workspace-desktop --features gpui-test --lib catalog_click_and_submission_reach_https_queue
cargo test --locked -p workspace-desktop --features gpui-test --lib explicit_topic_
cargo test --locked -p workspace-desktop --features gpui-test --lib history_keys_scroll_and_load_older_page
cargo test --locked -p workspace-desktop --features gpui-test --lib long_history_keeps_reading_position_and_input
```

Отдельный Cargo target исключает переиспользование тестов соседнего worktree. Нативный патч, команды и наблюдения одного окна сохраняются рядом с журналом миграции в `ui-12/`.
