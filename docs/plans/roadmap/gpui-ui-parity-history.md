Основа сравнения — Electron `workspace_ui@af0999886daaffefc2a7be33f8dcf3f484a0e9c1`. Использованы [фиксированные сцены UI-02](gpui-ui-parity-fixtures/README.md) и ширины области истории [из UI-05](gpui-ui-parity-shell.md). | Сценарий | GPUI и сопоставление с Electron |
| --- | --- |
| Личка и тема при 1440 и 700 px | История занимает 1061 и 340 px соответственно. Сверху панель 54 px. В личке она показывает имя и инициалы из каталога, в теме — её название и канал. Длинные заголовки ограничены шириной панели. Каталог применяется только для владельца и поколения открытого адреса. |
| Входящие и исходящие | Входящие слева, исходящие справа. Соседние сообщения одного известного автора, дня и темы сближены. В начале входящей группы есть подпись, в конце — общий аватар 40 px. Между днями видна отдельная метка. В узком окне текст занимает дополнительные строки. |
| Доставка | Ожидание, отправка, неизвестный исход и отказ подписаны рядом со значком. Подтверждённое сервером исходящее сообщение показывает время и одну галочку. Строка очереди исчезает при появлении того же UUID в истории. Цвет подложки берётся из Blue Mist, а подписи в пузырях используют читаемые цвета текста. |
| Загрузка и ошибка | Первичная загрузка и ошибка видны в центре истории. «Повторить» повторяет запрос, пустая тема показывает «Сообщений пока нет». Ошибка догрузки остаётся над имеющимися сообщениями вместе с кнопкой повтора. |
| Переход по UUID и к последним | Цель открытия привязана к верхнему краю списка. Метка дня встроена в строку и не меняет индекс UUID. При подгрузке высота переместившейся метки компенсируется. Кнопка «К последним» выводится снизу, если есть более новые страницы или пользователь выше хвоста истории. |

Имена и изображения участников канала, присутствие, количество участников и признаки прочтения отсутствуют в текущем снимке рабочего GPUI. Для неизвестного имени показываются подпись «Участник» и нейтральный аватар. Даты и время берутся из UTC серверной записи. Electron группирует по местному дню и использует относительные подписи «Сегодня» и «Вчера». Список показывает сохранённый текст, форматирование Markdown и действия над сообщениями идут по отдельным сценариям. При открытой теме внизу видна подпись о недоступности отправки. Для выбранной лички используется штатный редактор.

## Проверка

```sh
cargo test --locked -p workspace-desktop --features gpui-test --lib gpui_client::conversation
cargo test --locked -p workspace-desktop --features gpui-test --all-targets
```

`fixed_topic_groups_and_wraps_at_both_panel_sizes` подаёт тему и сообщения UI-02 в рабочий экран. Проверяет два размера, аватар на последнем сообщении группы, разделители дней, подпись канала и перенос длинной строки. `initial_error_retries_into_empty_topic` открывает тему, возвращает первичную ошибку и получает пустую историю после клика «Повторить». `preserves_visible_uuid_during_pages_and_updates` удерживает позицию пузыря при догрузке, когда разделитель дня переезжает выше. Допуск — 1 логический px. Остальные проверки покрывают переход к хвосту, недоступную цель, потерю доступа, ранний кэш и сверку очереди по UUID.
